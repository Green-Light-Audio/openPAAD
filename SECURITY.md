# Security policy

openPAAD runs on networked audio equipment. If you find a vulnerability
(for example a malformed packet that crashes or takes over a device), please
do not open a public issue. Report it privately through GitHub: on the
repository's Security tab, choose "Report a vulnerability". If that is not
possible, contact a maintainer listed in `MAINTAINERS` on GitHub and ask for
a private channel, without giving details in public. We acknowledge reports
within five working days and agree a disclosure date with you.
